# 03 — Google Business Profile status check (STRICT read-only)

Run this before any profile edit, and again after each edit stage.

Task: READ-ONLY status check of the Google Business Profile "<listing name>" (<city>, <street address>, phone <main phone>). The listing is managed from <owner's> Google account, which may be in a separate Chrome profile.

## Strict read-only mode
- Do NOT click any of these: Save, Edit-then-Save, Accept, Reject, Publish, Reply, Post, Delete, or any confirm button.
- Do NOT click "Own this business?", "Claim this business", "Request access", or any verification button.
- Do NOT change any field, attribute, hour, photo, service, review reply or manager setting.
- You may open edit dialogs only to READ the current values. Close them with Cancel / X.
- If a page asks you to confirm anything, stop and report it.
- Quote every value exactly as shown, in the original language. Do not summarise or translate values.
- Take a screenshot for every step and say which screenshot belongs to which step.

## Step 0 — Account and access
1. Switch to the Chrome profile signed in to the managing account. Report the profile name and the signed-in account (mask the email: first 3 letters + domain).
2. Open https://business.google.com/ and report every business listed under this account (name + address).
3. If "<listing name>" is NOT listed, stop and report what you see.
4. Open the listing → ⋮ → Business Profile settings → People and access. Report each person's role (Owner / Manager) and masked email, and any pending invitations.

## Step 1 — Profile data in the editor (read-only)
Open "Edit profile" and report the current value of every field, one line each:
- business name;
- primary category + all additional categories;
- description (full text + character count);
- opening date;
- phone (primary + additional);
- website;
- address, every field separately (country, street address, building/unit line, floor, postcode), plus service areas if any;
- hours: each day, special hours, "more hours" types;
- attributes: every attribute and its current value (parking, ownership attributes, accessibility, etc.);
- services/products: each item name, and whether it is marked pending;
- social profiles / booking links.

## Step 2 — Notices and pending changes
- Report any banner: "Google updated your profile", suggested edits, "under review", suspended, "verification required", duplicate profile.
- Open each notice and quote it. Do not accept or reject it.
- Report the verification status.

## Step 3 — Public view
Open Google Maps in the same profile and search "<brand> <district>". Then repeat in an Incognito window (signed out). For both, report:
- title, category, rating and review count;
- the full address line exactly as shown, including any building name;
- hours shown today and for the full week;
- phone and website shown;
- Plus Code;
- whether the description and services are visible;
- other businesses at the same pin / Plus Code (name + category), especially anything with a similar name.

## Step 4 — Reviews (read-only)
- Total number of reviews.
- For each review: date, star rating, whether an owner reply exists, and whether the reply is "under review" or failed.
- Do not quote reviewer names; use "Review 1, 2, ...".
- Flag patterns without accusing anyone: owner- or staff-written reviews, bursts, reviews from one-review accounts, scripted keyword wording, changes in the count.

## Step 5 — Other offices of the same brand (read-only)
Search Google Maps for "<brand> <city>" for each other office: <list>. For each one, report:
- whether it appears;
- address, phone and hours shown (flag "Open 24 hours");
- whether this account manages it (listed in business.google.com: yes/no).

## Step 6 — Insights (if available)
From the profile's Performance view, report the last 28 days: searches, views (Maps / Search), calls, website clicks, direction requests, and the top search terms if shown.

## Final report
- Steps 0–6 as separate sections, values quoted exactly.
- A list "Things that look wrong or inconsistent" (facts only, no fixes).
- End with: "No changes were made."
